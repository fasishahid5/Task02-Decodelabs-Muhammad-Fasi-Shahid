#  Expense Tracker – Python Project

A simple command-line Expense Tracker built using Python that allows users to input multiple expenses and calculates the total spending.

---

##  Features

- Add multiple expense amounts
- Real-time total calculation
- Input validation (handles invalid entries)
- Stop input using 'done'
- Final total summary display

---

##  Technologies Used

- Python 3
- Loops (while loop)
- Exception handling (try/except)
- Floating point calculations

---

##  How to Run

```bash
python expense_tracker.py
